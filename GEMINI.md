## Non-Negotiable Rules

1. **Observed State > Declared State**: Real code, tests, and Git history override any documentation.
2. **No DONE Without Evidence**: Never mark requirements or tasks as complete without test execution proof.
3. **Spec Before Implementation**: Formal contracts with IDs (`REQ-###`, `AC-###.#`, `TASK-###`).
4. **TDD Required**: Red-Green-Refactor for all non-trivial changes.
5. **Fresh Verifier**: Independent verification before state closure.
6. **Documentation From Reality**: Generate As-Built specifications after code verification.
